# MBA 备考中心

管理类联考（199）+ 英语二（204）备考工具集，含两个入口：

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 首页 | `index.html` | 两个工具的导航入口 |
| 真题模拟 | `exam/index.html` | 历年真题在线模考，2021–2026 入学年共 6 套、**630 题** |
| 英语作文背诵助手 | `essay.html` | 作文模板与范文背诵、复习计划（单文件独立网页） |

## 真题模拟功能

- 按考点比例自动抽题组卷
- 计时、暂停、交卷
- 自动打分
- 强弱项诊断

## 使用

在线直接打开首页 `index.html` 即可，**无需服务器、无需联网**。模考的题库与全部图片已加密内嵌于 `exam/`。

## 本地开发

```bash
python -m http.server 8899
# 访问 http://127.0.0.1:8899/index.html
```

## 技术说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 首页（静态，直接入库，不经密文构建） |
| `essay.html` | 英语作文背诵助手（单文件独立网页，源在 `E:\MBA\英语作文背诵助手.html`） |
| `exam/index.html` | 模考页面骨架 + 密文加载脚本标签 |
| `exam/secure.js` | 解密运行时（AES-256-GCM，密钥每次构建随机、混淆内嵌） |
| `exam/guard.js` | 前端防拷贝加固（右键/保存/拖图/devtools 警示） |
| `exam/engine.js` | 组卷、判分、诊断引擎 |
| `exam/app.js` | 界面与交互 |
| `exam/data/payload.enc.js` | 题库 + 词典 + 图片的 AES-256-GCM 密文（约 8 MB） |

> 2026-10-18 起站点分层：根目录 = 首页 + essay.html，模考系统整体迁入 `exam/` 子目录。
> `update.sh` 的密文构建目标已同步改为 `exam/`，构建绝不触碰根目录的首页。

模考的题库、词典（8516 条）、156 张题目图片均以 **AES-256-GCM 密文**形式发布，
页面加载时由 `secure.js` 解密写回 `BANK_DATA` / `WORD_DICT_DATA` / `ASSETS`
全局变量，下游引擎与交互层零改动。明文数据只存在于开发目录，绝不入库。

这意味着：右键「另存为」、查看源代码、`curl` 直链、`git clone` 拿到的都只是
密文——把「零成本扒走」提高到了「需要逆向 JS」。能力边界与完整方案见开发目录
`安全架构分析与加固方案.md`。

若修改了开发目录的题库，在开发目录重新执行构建并跑 `bash update.sh "说明"`
即可，密文与密钥会自动重新生成。首页源文件 = 开发目录 `home.html`，
作文助手源文件 = `E:\MBA\英语作文背诵助手.html`，两者均由 `update.sh` 自动同步入库。
